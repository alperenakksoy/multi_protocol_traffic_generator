Payload size, the GET/POST method mix, the number of multiplexed streams per connection, and the target paths for GET/POST requests (comma-separated, one chosen at random per request) can be changed at runtime via PATCH /generator/gen-http2. Sending pattern "Periodic burst" alternates between the base rate and Burst rate for Burst duration seconds every Burst interval seconds - visible as periodic spikes in Wireshark I/O graphs. "Random (Poisson)" keeps the same average rate but uses exponentially-distributed gaps between requests, mimicking bursty human-driven traffic.

Sending pattern
Payload size (bytes sent as the body of each HTTP/3 POST request) and the number of multiplexed streams per connection cycle can be changed at runtime via PATCH /generator/gen-quic. 0-RTT caches the TLS session ticket from the server and offers it on the next (re)connect; "used" only lights up once a connection actually resumed via 0-RTT instead of a full 1-RTT handshake. Sending pattern "Random (Poisson)" keeps the same average rate but uses exponentially-distributed gaps between connection cycles.

Sending pattern
Topic count selects how many topics (out of sensors/..., actuators/..., status/..., then load/topic-N) are used for publish and subscribe; changing it re-subscribes this generator. QoS distribution gives relative weights for QoS 0/1/2 on each publish; leave all at 0 to use a fixed QoS instead. This generator also subscribes to its own topics, so "Received" shows the broker's fan-out traffic. Sending pattern "Random (Poisson)" keeps the same average rate but uses exponentially-distributed gaps between publishes. Changes apply via PATCH /generator/gen-mqtt.

Pattern controls the overall sending cadence, independent of Normal/Stealth (which controls packet size). "Constant" sends one packet per interval derived from the rate; "Periodic burst" sends Burst size packets back-to-back, then idles for Burst interval; "Random" uses Poisson-distributed gaps between sends. Burst size/interval only apply to the periodic burst pattern. Changes apply via PATCH /generator/gen-tcpudp.
